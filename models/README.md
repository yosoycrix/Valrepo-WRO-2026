> [!NOTE]
> ### Guía de Uso de los Modelos
> 1. **Consultar la documentación específica:** Revisa el archivo README de cada subcarpeta para verificar tolerancias, notas de montaje y especificaciones técnicas.
> 2. **Descarga de archivos:** Obtén los archivos en formato <code>.STL</code> para laminación directa o utiliza el archivo <code>.STEP</code> alojado en <code>/Heimdall_final/</code> si requieres la geometría completa del ensamble en tu software CAD.
> 3. **Parámetros de impresión:** Aplica las recomendaciones de porcentaje de relleno (*infill*) y orientación de pieza para garantizar la resistencia mecánica del chasis.
